## Scoring change

Buying readiness now uses recorded seriousness (40%), decision access (30%), stakeholder coverage (20%) and stage/forecast (10%). A strong relationship or an unverified problem note does not raise that score. Engagement recency uses only buyer replies, meetings held, connected calls or completed substantive check-ins with a valid original date on or before today. A directly linked opportunity takes precedence over contact-only matching.

Outreach coordination can change the recommendation without clearing a recorded action or its due date. Review an active hold with its owner; passing the review date does not authorize outreach.

## Review and integration boundaries

### Local verification

On September 8, the complete `npm run check` passed: lint, 555 automated tests, and the optimized production build. An isolated browser walkthrough verified source-fact entry, a hold that remains active after its review date, a public-affiliation connection, saved-state reload, Connections, and Weekly Review with no browser runtime errors. Only synthetic test records were used; the normal local workspace was not changed. These are local verification results, not a GitHub upload or a production-readiness approval.

Additional regressions cover unknown activity dates remaining blank on edit, evening local-time captures crossing UTC midnight, unknown employment end dates, unresolved nurture triggers, completed next actions no longer appearing overdue, and ordinary SOSA proposals being unable to forge meeting-source provenance.

Use synthetic examples to check the brief's scenarios: an old forwarded reply, two opportunities at one account with an outreach hold, cross-account relationship links without merging, a community connection without invented revenue, similarly named organizations remaining distinct, and a signed engagement with separate start conditions. These tests do not load the named customers' private email or account records.

Retain the existing permission checks, source provenance, review-before-apply flow, deduplication and concurrent-update protection. New fields are additive; missing legacy context is not invented. Keep the existing production repository and services authoritative for identity, documents, approvals, billing and delivery systems. Integrate reviewed pieces through the documented adapters rather than replacing the production setup wholesale.
